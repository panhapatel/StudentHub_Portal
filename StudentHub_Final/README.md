# StudentHub Portal

Student portal built with HTML, CSS, JavaScript, Bootstrap, PHP and MySQL.

## Features
Registration, login (with Remember Me), dashboard with session timeout, profile (saved in DB),
fees, attendance, result, timetable, events (JSON + registration), FAQ (JSON) and contact form.

## Setup (XAMPP)
1. Copy this folder to `htdocs/`.
2. Start Apache and MySQL, then import `schema.sql` in phpMyAdmin.
3. Check the credentials in `db.php`.
4. Open `http://localhost/StudentHub_Final/index.html`.
